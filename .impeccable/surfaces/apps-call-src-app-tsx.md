# Call channel surface brief

Operate surface, desktop-first, ordinary extension of the approved Wager visual system.

## Direction contract
THESIS: a small real call workflow that continues existing support inquiries using independent demo customer verification.
OWN-WORLD: existing Wager Inter/system typography, light neutral or charcoal surfaces, green actions, subdued borders, clear semantic feedback. No new brand or illustrations.
STORY: start call, verify once, select real inquiry, hear status or request follow-up, end with persisted shared history. Unlinked anonymous activity remains private.
FIRST VIEWPORT: compact brand/settings header; left call console with service identity, elapsed time, prompt, digit keypad or inquiry menu and call controls; right transcript and selected case context. Empty and ended states retain truthful outcomes.
FORM: desktop split call console and conversation, collapsing vertically on narrow screens. User-pinned incumbent Wager system; no new direction selection needed.
SIGNATURE: verification unlocks the actual earlier conversation in the adjacent context panel. Spoken prompts always have visible text and keypad equivalents. Restrained 160ms color/state transitions, reduced motion respected.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
